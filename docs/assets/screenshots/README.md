# Current screenshots / Актуальные скриншоты

`current-overview.png` and `current-appearance.png` were supplied by the project
author on 2026-10-11. They capture the live desktop development build, including
translucency and compositor blur; they are not generated design mockups.

The README labels these as a development preview. Cadence v1.0.0 remains the
latest tagged release; Silverstar 1.1 application code is on
`codex/silverstar-convenience-1.1`. Design and runtime integration are still
being refined. A different shell revision, theme or machine can look different.

Wallpapers and device artwork shown inside the application are not separately
licensed project assets. Earlier screenshot files in this directory are
historical and are no longer embedded in the README.
