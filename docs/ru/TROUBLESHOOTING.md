# Решение проблем

## Установщик не видит runtime ii

Miko Control Center расширяет runtime `illogical-impulse`. В выбранном корне
Quickshell должны существовать:

```text
modules/common/
modules/common/widgets/
services/
```

Если совместимый runtime лежит в другом месте, задайте `MIKO_QS_ROOT`.
`--force` пропускает только проверку каталогов и не создаёт отсутствующие QML-
импорты.

## Приложение не появляется

Запустите лаунчер в терминале:

```bash
miko-control-center
```

Проверьте:

```bash
${XDG_STATE_HOME:-$HOME/.local/state}/miko-control-center.log
qs list --all
```

Лаунчер открывает существующий экземпляр через IPC либо запускает отдельный
процесс Quickshell.

## Окно тайлится слишком маленьким

Некоторые Wayland-композиторы игнорируют минимальный размер Qt. Добавьте правило
по точному title `Miko Control Center` либо сделайте окно плавающим вручную.
Репозиторий не меняет конфигурацию композитора.

## Карточка недоступна

Запустите:

```bash
./scripts/doctor.sh
```

Большинство интеграций зависят от внешней команды. Одной установки программы
может быть недостаточно, если служба, разрешения или API выключены.

## Не работают действия с телефоном

Проверьте:

- наличие `kdeconnect-cli`;
- pairing и доступность обоих устройств в LAN;
- нужный плагин KDE Connect на телефоне;
- разрешение Android на файлы или буфер.

Просмотр файлов Android может оставаться недоступным, даже когда обычная
передача работает.

## В Throne мало данных

Базовое состояние читается без live API. Скорость, соединения и процессы требуют
совместимого API Throne. Центр управления самостоятельно его не включает и не
переписывает конфигурацию.

## Обновление просит пароль или завершается ошибкой

Проект не устанавливает sudoers и polkit-правила. Используйте штатную
авторизацию дистрибутива. Не выдавайте центру неограниченный беспарольный root.

## Как вернуть предыдущую установку

Backup установщика:

```text
${XDG_STATE_HOME:-$HOME/.local/state}/miko-control-center/backups/
```

Файлы после удаления:

```text
${XDG_STATE_HOME:-$HOME/.local/state}/miko-control-center/removed/
```

Восстанавливайте их, когда отдельный процесс центра управления не использует
эти файлы.
