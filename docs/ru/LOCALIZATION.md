# Локализация

Miko Control Center хранит локализацию внутри проекта и не изменяет переводы,
которые поставляет окружение `illogical-impulse`.

## Как это работает

- Русский текст в QML — стабильный исходный ключ и встроенный fallback.
- `src/controlcenter/I18n.qml` определяет активный язык и загружает JSON-каталог
  из `src/controlcenter/i18n/`.
- Режим `auto` сначала использует язык оболочки, затем локаль Qt.
- При смене языка существующие bindings обновляются сразу; перезапуск центра не
  нужен.
- Выбор пользователя сохраняет `ControlCenterState`.

Переменная `MIKO_CONTROL_CENTER_LANGUAGE` временно переопределяет выбор
значением `ru_RU` или `en_US`. Она нужна для превью и smoke-тестов, а не для
постоянной настройки.

## Перевод текста интерфейса

Пользовательские строки QML оборачиваются в `I18n.tr`:

```qml
StyledText {
    text: I18n.tr("Система в порядке")
}
```

Предложения с данными нужно собирать через именованные подстановки, а не
склеивать из переведённых кусочков:

```qml
text: I18n.tr("Проверено {time}", { time: controller.checkedAt })
```

После этого точный исходный ключ добавляется в каталог:

```json
{
  "Проверено {time}": "Checked {time}"
}
```

Названия команд, протоколов, продуктов и единицы измерения не переводятся,
если именно так пользователь видит их в остальной системе.

## Добавление языка

1. Добавить локаль в `I18n.languages`.
2. Создать `src/controlcenter/i18n/<locale>.json`.
3. Перевести все ключи, которые показывает `./scripts/check-i18n.sh`.
4. Использовать общий список `I18n.languages`; не делать отдельные кнопки языка
   внутри страниц.
5. Проверить переключение на новый язык и обратно без перезапуска.

Перед коммитом запускается полная проверка:

```bash
./scripts/check.sh
```

Она отклоняет повреждённые каталоги, пустые переводы, отсутствующие английские
ключи и новые необёрнутые кириллические строки интерфейса.
